# NEXORA AI — Hero Background Image

Place the hero background photo here as:
  hero-bg.jpg

This file is referenced at:
  /assets/hero-bg.jpg   (Vite serves everything in /public/ at root)

Both the Landing Page and Login Page use this image.
If the file is absent, a matching CSS gradient (deep dusk blue ? teal ? dark navy) 
is shown automatically as a fallback — the app works without it.

To set a different image via the admin panel:
  1. Log in as Super Admin
  2. Go to Settings ? Branding
  3. Upload / enter a URL in "Background Image URL"
  4. Save — the change propagates to Landing + Login pages immediately.
